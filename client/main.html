Frequently Asked Questions

FlixNova is a data analyst portfolio project — a movie browsing platform enhanced with machine learning (content-based recommendations), NLP sentiment analysis, and a live analytics dashboard.
It uses content-based filtering with TF-IDF vectorization on genre, plot, and cast metadata. Cosine similarity scores determine how similar two movies are. This is the same core technique used by Netflix and Spotify.
The data pipeline uses pandas (data wrangling), scikit-learn (TF-IDF + cosine similarity), TextBlob / VADER (sentiment analysis), and matplotlib (chart generation). The frontend uses Chart.js for interactive visualizations.
It computes a polarity score between −1 (very negative) and +1 (very positive) using a lexicon-based approach — assigning sentiment weights to words and aggregating them. Production systems would fine-tune BERT or RoBERTa on movie review datasets.
Movie metadata is fetched live from the OMDb API. For analytics and ML, the TMDB 5000 Movies dataset (available on Kaggle) can be used to train the recommendation model with thousands of entries.
